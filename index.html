不是荐股软件，是一套研究流程

它是什么

部署在自己电脑或服务器上的 A 股量化研究工具：本地数据湖、全市场真实竞价、一进二选票、自动复盘，以及网页看板 / 微信推送两个出口。

它不是什么

不连接券商、不代下单、不经手资金，也不承诺收益。它不预测“明天一定涨”，买卖决定仍由使用者自己承担。

一天怎么跑

09:25

竞价定盘

采集全市场真实竞价，等全市场定盘后再选票。

09:27

一进二候选

硬闸 + 评分 + 板块共振，给出 ≤3 只候选与推送。

盘中

实时更新

实时数据每分钟更新；看板可用预测与深度分析，也能随时问 AI。

盘后

复盘与观察

命中、遗漏、盲区自动归档，生成明日观察。

推送方式 微信 · 企业微信 · 钉钉 · 飞书 · DSH-IM

核心能力

一进二寻龙

全市场首板扫描，十余道硬闸 + 多维评分，09:25 竞价定盘后给出候选（≤3 只）。

每日自动复盘

收盘后汇总命中、遗漏、盲区，另附「不该漏」清单，写清楚漏在哪里。

明日观察

结合涨停梯队、板块合力、封板质量与竞价抢筹，梳理次日关注方向。

个股 / 大盘预测

发代码即回方向参考与关键指标；也能看当日涨跌家数、情绪档位与大盘系数。

深度分析

拉取长周期价量序列做结构化解析，辅助判断主力行为痕迹。

两个出口

数据底座与工程可信度

数据底座

  • 十年全市场日线：2016 → 今，五千余只标的，未复权原始数据 + 完整复权因子事件流。
  • 真实竞价明细：竞价成交量额、未匹配量、竞价换手率、量比、占昨日成交量比，每日每票一行。
  • 涨停与梯队：涨停池、炸板池、跌停池、连板梯队矩阵，含权威连板数与涨停原因。
  • 资金与热度：龙虎榜机构 / 游资净买卖、热股榜与排名趋势、个股异动原因。
  • 板块体系：行业与概念指数成分股，可做行业级与概念级共振分析。
  • 指数与估值：宽基 / 行业 / 概念指数日线与指标，以及市盈率、市净率、市销率快照。

工程可信度

53 条质量断言
3 条复权不变量
16 个自动作业
325 MB常驻内存
  • 一条命令跑完盘后：xlp daily 增量入库 → 复权口径 → 物化指标 → 池与指数 → 质量闸。
  • 原始层只追加不覆盖，同一主键重复写入会报错。
  • 16 个作业由代码声明，一个 funboost 调度服务统一定时，休市日自动跳过。
  • 只备份不可再生的原始层与状态库，逐文件校验和，恢复前可先做一次不落地的演练。
  • 不写死胜率，战绩由 xlp stats 用你自己库里的真实自评现算。
