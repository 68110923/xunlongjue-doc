A 股主板 · 一进二竞价打板量化系统
一进二 竞价选股 全市场扫描 技术面筛选 每日复盘 数据看板

🎯 这是什么

一套部署在自己电脑或服务器上的 A 股量化研究工具。 它在本地维护一份覆盖十年全市场的数据湖， 每个交易日自动完成：盘前竞价采集 → 一进二选票 → 盘中强多扫描 → 盘后复盘与明日观察，全部结果结构化落表。

结果有两个出口：网页看板随时查看，或推送到微信（含 AI 分析）。 两者都从同一份数据取数、互不依赖；核心层不依赖 AI， 没有 AI 也照常运行。

不连接券商账户、不代下单、不经手资金 —— 它只做「整理数据 + 给出研究结论」。

🧩 功能

一进二寻龙

全市场首板扫描，十余道硬闸 + 多维评分，每天 9:25 竞价定盘后给出候选。

  • 封板时间、封板资金、连板数、板块共振
  • 竞价涨幅、竞价额、竞价未匹配量、竞价量比
  • 每只票附「买点类型 + 触发条件 + 放弃条件」

全市场选好票

按技术面多维打分筛选强多票，盘中可多次重算，并留存在榜/掉出轨迹。

  • 均线 / KDJ / MACD / 布林带多维打分
  • 入选时间、掉出时间、掉出原因可追溯

每日自动复盘

收盘后自动汇总当日结果：✅ 命中 / ⚠️ 遗漏 / 🔴 盲区， 另附一份「不该漏」清单 —— 漏在哪里、为什么漏，写清楚。

明日观察

盘后结合涨停梯队、板块合力、封板质量与竞价抢筹，梳理次日关注方向， 并对「虚高开盘」一票否决。

个股 / 大盘预测

对话式查询：发代码即回方向参考与关键指标；也能看当日涨跌家数、情绪档位与大盘系数。

深度分析

拉取长周期价量序列做结构化解析（形态、量能、指标分位），辅助判断主力行为痕迹。

📊 数据能力

十年全市场日线

2016 → 今，全市场五千余只标的，未复权原始数据 + 完整复权因子事件流（含配股）。

真实竞价明细

竞价成交量额、未匹配量、竞价换手率、竞价量比、占昨日成交量比； 2026-09 起全市场每日每票一行（不再只有池内票）。

涨停与梯队

涨停池、炸板池、跌停池、连板梯队矩阵， 含权威连板数与涨停原因。

资金与热度

龙虎榜（机构 / 游资净买卖）、热股榜与排名趋势、个股异动原因。

板块体系

同花顺行业与概念指数成分股，可做行业级与概念级共振分析。

指数与估值

宽基 / 行业 / 概念指数日线与指标（523 个）， 以及市盈率 / 市净率 / 市销率快照。

全部落在本地数据湖：17 张表按主键只追加不覆盖， 每个批次带血缘（批次号 + 入库时间），原始层永不修改、派生层随时可重建。 消费方（看板 / 脚本 / AI）只读视图 v_*，底层换实现上层无感。

🛡️ 工程与可靠性

一条命令跑完盘后

xlp daily：增量入库 → 复权口径 → 物化指标 → 池与指数 → 质量闸， 失败即退出码非零。

可验证，不靠感觉

51 条质量断言 + 3 条复权不变量（前复权末根=真实价、 后复权首根=真实价、因子恒为正），每个交易日自动跑。

小机器跑得动

实测 2 核 2 GB：常驻约 325 MB，最重作业峰值约 1.1 GB； 全市场竞价 56 个请求并发后约 5 秒。

数据可追可回滚

同一主键重复写入会报错而不是静默覆盖； 修复后按分区压实去重，读取永远取最新版本。

备份与演练

只备份不可再生的原始层与状态库（约 193 MB / 2.3 秒）， 逐文件校验和，恢复前可先做一次不落地的演练。

定时任务单一真源

16 个作业的命令与计划由代码声明，一键安装 systemd / crontab， 改调度不用手抄。

🚀 怎么用

  1. 在一台 2 核 2 GB 的 Linux（或自己的电脑）上部署 —— 一条安装命令搞定依赖
  2. 首次回填十年历史数据：xlp backfill --years 10（约 10~20 分钟）
  3. 装定时任务：xlp cron install --system —— 16 个作业自动运行
  4. 每个交易日到点出结果：竞价与选票 09:25、盘中扫描每 30 分钟、复盘 16:08、明日观察 16:14
两种使用方式
· 源码版：部署到自己的环境，功能完整，可自行接入 AI 与扩展；
· 看板版：无需部署，登录网页查看结果。

⚙️ 系统要求

  • 2 核 2 GB / Ubuntu 22.04+ / 磁盘 ≥ 10 GB（湖约 0.7 GB + 缓存与备份）
  • 系统时区 Asia/Shanghai（时区不对，定时任务会整体偏移且不报错）
  • 数据源 API Key：自备、自付（数据来自同花顺金融数据 API）
  • AI 增强层（微信推送 / 对话）可选，需要自行准备模型 API Key； 不装也完全可用
