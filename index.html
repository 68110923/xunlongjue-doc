不是荐股软件，是一套研究流程

它是什么

部署在自己电脑或服务器上的 A 股短线研究工具：竞价解读、一进二选票、个股预测、主力痕迹、仓位与复盘，以及网页看板 / 微信推送两个出口。一进二只是入口，不是全部。

它不是什么

不连接券商、不代下单、不经手资金，也不承诺收益。它不预测“明天一定涨”，买卖决定仍由使用者自己承担。

今天该进攻，还是先防守？

先给你一个仓位区间

根据大盘趋势和市场热度，每天给一个参考仓位，不是一句“满仓干”。

  • 防守 0~2 成：大盘走弱、赚钱效应差
  • 均衡 3~5 成：方向不明、结构行情
  • 进攻 6~8 成：趋势向上、情绪回暖

为什么是这个仓位？

看大盘趋势、涨跌家数、涨停/跌停、炸板率、市场中位数、最高连板；早上给当天，收盘给明天。

仓位是研究参考，不构成投资建议；买卖决定仍由你自己做。

核心能力

一进二是入口，不是全部：预测、深度分析、仓位和复盘，每天都能用上。

一进二寻龙

早上告诉你：今天哪几只首板值得盯，最多 3 只，附上入选理由。

每日自动复盘

收盘告诉你：选对了没、漏了谁、为什么漏，明天别再错过。

明日观察

明天重点看哪些方向、哪些票，不用自己翻全市场。

个股 / 大盘预测

发个代码，给方向参考；大盘冷热、涨跌家数也能一眼看懂。

深度分析

一只票的价量、资金痕迹和关键位置，整理成一页。

两个出口

网页看板、微信推送都能看；不用装 App，随时打开。

数据可靠，结果可核对

数据底座

  • 十年全市场日线：2016 → 今，五千余只标的，未复权原始数据 + 完整复权因子事件流。
  • 真实竞价明细：竞价成交量额、未匹配量、竞价换手率、量比、占昨日成交量比，每日每票一行。
  • 涨停与梯队：涨停池、炸板池、跌停池、连板梯队矩阵，含权威连板数与涨停原因。
  • 资金与热度：龙虎榜机构 / 游资净买卖、热股榜与排名趋势、个股异动原因。
  • 板块体系：行业与概念指数成分股，可做行业级与概念级共振分析。
  • 指数与估值：宽基 / 行业 / 概念指数日线与指标，以及市盈率、市净率、市销率快照。
