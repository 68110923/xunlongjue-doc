🎯 这是什么

一套部署在自己电脑或服务器上的 A 股量化研究工具。 它在本地维护一份覆盖十年全市场的数据湖， 每天自动完成首板扫描、竞价评分、技术面筛选与收盘复盘，并把结果结构化落表。

结果有两个出口：推送到微信（含 AI 分析）， 或经网页看板随时查看。两者都从同一份数据取数，互不依赖。

🧩 功能

一进二寻龙

全市场首板扫描，多道硬逻辑 + 多维评分，每天 9:25 竞价结束后给出候选。

  • 封板时间、封板资金、连板数
  • 竞价涨幅、竞价额、竞价未匹配量
  • 每只票附「买点类型 + 触发条件 + 放弃条件」

全市场选好票

按技术面多维打分筛选强多票，盘中可多次重算，并留存在榜/掉出轨迹。

  • 均线 / KDJ / MACD / 布林带多维打分
  • 入选时间、掉出时间、掉出原因可追溯

每日自动复盘

收盘后自动汇总当日结果，推了什么、表现如何，一目了然。

个股 / 大盘预测

对话式查询：发代码即回方向参考与关键指标。

深度分析

拉取长周期价量序列做结构化解析，辅助判断主力行为痕迹。

明日观察

盘后结合涨停梯队、板块合力与封板质量，梳理次日关注方向。

📊 数据能力

十年全市场日线

2016 → 今，全市场五千余只标的，未复权原始数据 + 完整复权因子事件流（含配股）。

真实竞价明细

竞价成交量额、未匹配量、竞价换手率、竞价量比、占昨日成交量比。

涨停与梯队

涨停池、炸板池、跌停池、连板梯队矩阵，含权威连板数与涨停原因。

资金与热度

龙虎榜（机构/游资净买卖）、热股榜与排名趋势、个股异动原因。

板块体系

同花顺行业与概念指数成分股，可做行业级与概念级共振分析。

估值与财务

市盈率 / 市净率 / 市销率快照，以及成长、盈利、偿债、营运、现金流五类指标。

🚀 怎么用

  1. 在自有电脑或服务器上部署（附部署教程，也可协助远程部署）
  2. 自动回填十年历史数据（首次约数分钟）
  3. 按需绑定推送渠道，或直接打开网页看板
  4. 每个交易日自动运行，结果到点可见
两种使用方式
· 源码版：部署到自己的环境，功能完整，可自行接入 AI 与扩展；
· 看板版：无需部署，登录网页查看结果。
