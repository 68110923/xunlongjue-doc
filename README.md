## 🎯 这是什么

一套**部署在自己电脑或服务器上**的 A 股量化研究工具。它在本地维护一份覆盖**十年全市场**的数据湖，
每个交易日自动完成：盘前竞价采集 → 一进二选票 → 盘中强多扫描 → 盘后复盘与明日观察，
全部结果结构化落表。

结果有两个出口：**网页看板**随时查看，或**推送到微信**（含 AI 分析）。两者都从同一份数据取数、
**互不依赖**；核心层**不依赖 AI**，没有 AI 也照常运行。

不连接券商账户、不代下单、不经手资金 —— 它只做「整理数据 + 给出研究结论」。

```
                    ┌─→ 网页看板（只读表，零 LLM）
xlp 核心层（写表）──┤
                    └─→ 微信推送 / 对话（AI 增强层，可选）
```

## 🧩 功能

| 功能 | 说明 |
|---|---|
| **一进二寻龙** | 全市场首板扫描，十余道硬闸 + 多维评分，每天 **9:25 竞价定盘后**给出候选（≤3 只）。每只票附「买点类型 + 触发条件 + 放弃条件」；判据含封板时间、封板资金、连板数、板块共振、竞价涨幅、竞价额、**竞价未匹配量**、竞价量比 |
| **全市场选好票** | 按技术面多维打分筛选强多票（均线 / KDJ / MACD / 布林带），盘中每 30 分钟重算，留存在榜与掉出轨迹（入选时间、掉出时间、掉出原因） |
| **每日自动复盘** | 收盘后汇总当日结果：**✅ 命中 / ⚠️ 遗漏 / 🔴 盲区**，另附一份「不该漏」清单 —— 漏在哪里、为什么漏，写清楚 |
| **明日观察** | 盘后结合涨停梯队、板块合力、封板质量与竞价抢筹，梳理次日关注方向，并对「虚高开盘」一票否决 |
| **个股 / 大盘预测** | 发代码即回方向参考与关键指标；也能看当日涨跌家数、情绪档位与大盘系数 |
| **深度分析** | 拉取长周期价量序列做结构化解析（形态、量能、指标分位），辅助判断主力行为痕迹 |
| **两个出口** | 网页看板（只读产物、自动刷新）/ 微信推送（含 AI 分析）；**任选其一或都要**，互不依赖 |
