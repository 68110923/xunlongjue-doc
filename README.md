## 🎯 这是什么

一套**部署在自己电脑或服务器上**的 A 股量化研究工具。它在本地维护一份覆盖**十年全市场**的数据湖，
每个交易日自动完成：盘前竞价采集 → 一进二选票 → 盘中强多扫描 → 盘后复盘与明日观察，
全部结果结构化落表。

结果有两个出口：**网页看板**随时查看，或**推送到微信**（含 AI 分析）。两者都从同一份数据取数、
**互不依赖**；核心层**不依赖 AI**，没有 AI 也照常运行。

不连接券商账户、不代下单、不经手资金 —— 它只做「整理数据 + 给出研究结论」。

```
                    ┌─→ 网页看板（只读表，零 LLM）
xlp 核心层（写表）──┤
                    └─→ 微信推送 / 对话（AI 增强层，可选）
```

- **回测不再留空**：窗口没走完时用盘中最高兜底并标 `*`、表尾自动脚注，收盘重跑星号消失；7 日最佳均值统计全部推送行
- **平均涨跌坚持收盘口径**：推送日尚未收盘的标的不计入平均涨跌，避免盘中价混进「最新收盘价」
- **明日观察篇幅规范**：单票 30～60 字、操作思路 150～300 字，要求说人话、单条描述最多留一个数字当证据
- **明日观察放弃价约束**：所有“跌破放弃”的价格必须使用预计算的支撑价，禁止拿跌停价代替
- **观察字段用途表**：明确首板日价格、次日涨跌停价和支撑价各自用途，避免把跌停价当支撑
- **观察操作思路改为口语式**：按股票顺序直接写“竞价条件 + 动作”，不写“预期1/2”和优先级标签；一字挂单不再附加“开盘不破”

### V20261101 (2026-11-01)
- **一进二低位过滤**：首板需满足开盘价、最低价相对布林下轨的分层条件，或收盘突破布林上轨；中轨仍下行的首板不进入候选；次新股历史不足时不适用
- **BOLL 动态评分扩展**：中轨趋势、开盘/最低价相对下轨的位置、收盘突破上轨、最低价跌破下轨分别计入评分；具体阈值走参数版本管理
- **首板高开低走过滤**：首板竞价涨幅较高、但盘中最低涨幅明显回落的首板直接淘汰
- **竞价成交额分档硬闸**：按流通市值多档设置竞价成交额下限，未达到下限的首板直接淘汰
- **一进二市值门槛调整**：流通市值下限调整，具体值走参数版本管理
- **回测日期修正**：回测表格显示推送日/竞价日，首板日单独保留，避免把首板日误读成执行日
- **回测汇总口径修正**：诊断模式只增加诊断行，平均涨跌、命中率和 7 日最佳始终只统计推送行
- **回测 7 日最佳口径**：买入日开盘价到之后 7 个交易日内最高价；买入当天不能卖、不计入，不足 7 个交易日取已有最高价
- **回测标准模板精简**：默认只展示日期、股票名称、是否命中、7 日最佳
- **价格与常见问题优化**：突出划线价与正式价，补充源码买断含后续策略更新、小配置服务器运行、试用等说明
- **观察产物预计算**：为每只标的提供板位标签、涨停原因和概念板块；支撑字段保留给数据消费，但操作思路不再引用
- **明日观察模板精简**：单票描述压缩、操作思路限定篇幅、数字不堆砌，并明确禁止未提供的题材

### V20261031 (2026-10-31)
- **交易日历统一**：复盘、观察、指标、补数、交割日提醒等日期窗口统一按交易所交易日表计算，不再混用自然日、周末和湖内实际日期
- **交易日历自动维护**：本地交易日文件缺失或临近到期时自动更新，长假、跨年和补数据场景不再依赖手工维护
- **BOLL 口径对齐**：标准差改为样本口径，与常用看盘软件显示一致；历史 BOLL 已批量重算
- **指标内存优化**：下调指标预热窗口，降低盘中常驻内存；常用指标保持稳定，超长周期指标按近似值展示
- **盘中快照优化**：实时行情改为更紧凑的内存结构，减少每分钟内存分配和抖动
- **前收数据修复**：修复批量读取 K 线时前收为空的问题，低吸参考价、跌停价和支撑位恢复完整
- **明日观察精简**：观察池只保留程序筛选后的少量标的，AI 最终按需给出，不再为了凑数量保留低质量票
- **历史能力清理**：移除已下线的旧选票、旧轨迹和冗余输出模板，相关文档同步更新
- **指标计算一致性**：指标预热窗口、盘中连续性和日线口径统一，避免盘后与盘中出现两套日期/窗口算法
- **测试补强**：交易日历、指标连续性、BOLL 重算、产物一致性和数据修复均有回归覆盖

### V20261028 (2026-10-28)
- **早盘输出统一**：整体盘面与早盘简报采用统一模板，压缩篇幅、只保留用户需要看的信息
- **上证信号恢复**：恢复五档信号，并与预测标签共用一套评分格式
- **竞价连板补充**：早盘盘面加入竞价连板数据，板块强弱判断更完整
- **交割日提醒恢复**：股指期货交割日提醒重新接入，并复用交易日历计算
- **AI 模板入口统一**：输出模板收口到一个入口，早盘、复盘、观察不再各用一套
- **项目入口收口**：技能与部署文档统一为单项目入口，减少重复配置

### V20261027 (2026-10-27)
- **复盘覆盖全部板块**：创业板、科创板纳入命中、遗漏、盲区；首板池、过闸候选和推送分开计数，不再出现“首板多少、候选就是多少”

- **深度分析升级**：支持指数与当日盘中快照；内嵌预测去掉重复趋势，窗口更轻、更省上下文
- **历史数据下载**：生成数据湖快照并提供下载，旧数据库链接自动跳转到新快照
- **推送配置收敛**：部署文档合并，固定盘前与盘后两个推送作业；产物过期时不再发送
- **预测收敛**：只预测单票或指数，盘中自动使用当日快照，不再提供全市场预测入口
- **数据质量治理**：过滤异常池记录，修复竞价派生字段，回填历史换手率，并加强质量断言
- **失败告警**：关键作业失败自动记录，可选推送告警
- **AI 输入标准化**：预测、深度分析、评估、统计、回测和盘面均支持结构化输出，AI 不再猜输出格式
