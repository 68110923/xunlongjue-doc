## 🎯 这是什么

一套**部署在自己电脑或服务器上**的 A 股量化研究工具。它在本地维护一份覆盖**十年全市场**的数据湖，
每个交易日自动完成：盘前竞价采集 → 一进二选票 → 盘中强多扫描 → 盘后复盘与明日观察，
全部结果结构化落表。

结果有两个出口：**网页看板**随时查看，或**推送到微信**（含 AI 分析）。
两者都从同一份数据取数、**互不依赖**；核心层**不依赖 AI**，没有 AI 也照常运行。

不连接券商账户、不代下单、不经手资金 —— 它只做「整理数据 + 给出研究结论」。

```
                    ┌─→ 网页看板（只读表，零 LLM）
xlp 核心层（写表）──┤
                    └─→ 微信推送 / 对话（AI 增强层，可选）
```

## 🧩 功能

| 功能 | 说明 |
|---|---|
| **一进二寻龙** | 全市场首板扫描，十余道硬闸 + 多维评分，每天 **9:25 竞价定盘后**给出候选。每只票附「买点类型 + 触发条件 + 放弃条件」；判据含封板时间、封板资金、连板数、板块共振、竞价涨幅、竞价额、**竞价未匹配量**、竞价量比 |
| **全市场选好票** | 按技术面多维打分筛选强多票（均线 / KDJ / MACD / 布林带），盘中可多次重算，留存在榜与掉出轨迹（入选时间、掉出时间、掉出原因） |
| **每日自动复盘** | 收盘后汇总当日结果：**✅ 命中 / ⚠️ 遗漏 / 🔴 盲区**，另附一份「不该漏」清单 —— 漏在哪里、为什么漏，写清楚 |
| **明日观察** | 盘后结合涨停梯队、板块合力、封板质量与竞价抢筹，梳理次日关注方向，并对「虚高开盘」一票否决 |
| **个股 / 大盘预测** | 发代码即回方向参考与关键指标；也能看当日涨跌家数、情绪档位与大盘系数 |
| **深度分析** | 拉取长周期价量序列做结构化解析（形态、量能、指标分位），辅助判断主力行为痕迹 |

| **资金与热度** | 龙虎榜（机构 / 游资净买卖）、热股榜与排名趋势、个股异动原因 |
| **板块体系** | 同花顺行业与概念指数成分股，可做行业级与概念级共振分析 |

> 全部落在**本地数据湖**：**17 张表**按主键只追加不覆盖，每个批次带血缘（批次号 + 入库时间），
> 原始层永不修改、派生层随时可重建。消费方（看板 / 脚本 / AI）**只读视图 `v_*`**，底层换实现上层无感。

## 🚀 怎么用

1. 在一台 **2 核 2 GB** 的 Linux（或自己的电脑）上部署 —— 一条安装命令搞定依赖
2. 首次回填十年历史数据：`xlp backfill --years 10`（约 10~20 分钟）
3. 装定时任务：`xlp cron install --system` —— 16 个作业自动运行
4. 每个交易日到点出结果：竞价与选票 **09:25**、盘中扫描**每 30 分钟**、复盘 **16:08**、明日观察 **16:14**

> **两种使用方式**
> · **源码版**：部署到自己的环境，功能完整，可自行接入 AI 与扩展；
> · **看板版**：无需部署，登录网页查看结果。
