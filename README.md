## 🎯 这是什么

一套部署在自己电脑或服务器上的 A 股量化研究工具。它在本地维护一份覆盖十年全市场的数据库，每个交易日自动完成：盘前竞价采集 → 一进二选票 → 盘中实时数据 → 盘后复盘与明日观察。

结果有两个出口：网页看板随时查看，或推送到微信（含 AI 分析）。两者都从同一份数据取数、互不依赖；核心层不依赖 AI，没有 AI 也照常运行。

不连接券商账户、不代下单、不经手资金 —— 它只做「整理数据 + 给出研究结论」。

```text
                    ┌─→ 网页看板（只读表，零 LLM）
xlp 核心层（写表）──┤
                    └─→ 微信推送 / 对话（AI 增强层，可选）
```
