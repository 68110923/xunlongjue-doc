购买与交付

交付什么形式？

私有仓库只读 PAT + 数据快照密码 + 部署教程 + 全部文档；把部署页的两段话交给 AI 即可代你装好。

后续策略更新怎么拿？

源码买断包含后续策略更新，作者打包到私有仓库，买家通过 git pull 同步，不另收费。

怎么试用？

88 元看板试用 7 个交易日，不含源码，结果在看板内查看；试用期内购买源码可全额抵扣。

不会部署怎么办？

可以按部署文档自己安装；也可选 200 元远程协助（约 2 小时）；暂时不部署可先申请看板试用。

怎么咨询 / 试用？

购买源码：付款备注微信，加微信后拉进微信交流群；试用 / 看板：付款后申请看板账号（需审核），交流在看板内的聊天。

已购买原版，怎么升级 PRO？

原版 xunlongjue 同为 1288 元；已购买原版的老用户可直接同步 PRO 版源码，联系作者或在微信交流群里说一声即可。

源码能二次开发吗？

可以。交付完整源码、文档和 CLI，可在自己的项目里引用；禁止转售或再分发源码本身。

部署与环境

部署需要什么环境？

Ubuntu 22.04+ 或自己的电脑，磁盘不少于 10 GB；系统时区必须是 Asia/Shanghai，否则定时任务会整体偏 8 小时且不报错。

2 核 2 GB 能跑吗？

支持。实测可稳定运行，常驻约 325 MB，最重作业峰值约 1.1 GB；也可以装在自己电脑上。

数据源 Key 谁付？

数据源免费，配置随交付提供；额外成本只有可选 AI 的 token 费用，约 0.2 元/天。

多久出结果？

竞价与选票在 09:26 前后；看天 09:27；盘中实时数据每分钟更新，预测与深度分析随时可用；复盘 16:19；明日观察按需生成。

使用与能力

这是什么？

部署在自己电脑或服务器上的 A 股量化研究工具：本地数据湖、一进二选票、自动复盘、网页看板与微信推送；核心层不依赖 AI。

完全不懂股票能用吗？

能看懂输出，但仍需自己判断。系统只给研究结论，不代下单、不承诺收益；建议先用看板试用。

会自动下单吗？

不会。不接券商、不代下单、不经手资金。

不接 AI 能用吗？

能。核心层零 LLM，数据、选票、复盘照常运行；AI 只负责推送话术和问答。

需要会编程吗？

不需要。装好后每天自动运行，结果在网页看板或微信里查看；会命令行更便于排障。

数据与稳定

数据保存在哪里？

全部保存在你自己的电脑或服务器，不经过第三方；源码通过私有仓库只读 PAT 交付。

和别家有什么区别？

源码买断后持续维护，策略长期更新：后续策略更新通过私有仓库 git pull 同步，不另收费；参数重标定、回测和自评脚本随版本更新。再加上全市场真实竞价、权威涨跌停口径、53 条质量断言与可复权的本地数据湖，重点是可核对、能长期用。

软件稳定吗？

原版与 PRO 版同一条路线已持续实盘运行超过一年，核心链路每日自动执行。

策略会不会失效？

市场会变，不承诺永远有效；策略经过长期实盘验证与历史回测，仓库带有重标定与自评脚本。
