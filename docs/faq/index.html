常见问题

购买、部署、数据、稳定性和二次开发。

这是什么？

部署在自己电脑或服务器上的 A 股量化研究工具：本地数据湖、一进二选票、自动复盘、网页看板与微信推送；核心层不依赖 AI。

完全不懂股票能用吗？

能看懂输出，但仍需自己判断。系统只给研究结论，不代下单、不承诺收益；建议先用看板试用。

会自动下单吗？

不会。不接券商、不代下单、不经手资金。

部署需要什么环境？

Ubuntu 22.04+ 或自己的电脑，磁盘不少于 10 GB；系统时区必须是 Asia/Shanghai。

数据源 Key 谁付？

数据源免费，配置随交付提供；额外成本只有可选 AI 的 token 费用，约 0.2 元/天。

不接 AI 能用吗？

能。核心层零 LLM，数据、选票、复盘照常运行；AI 只负责推送话术和问答。

数据保存在哪里？

全部保存在你自己的电脑或服务器，不经过第三方；源码通过私有仓库只读 PAT 交付。

需要会编程吗？

不需要。装好后每天自动运行，结果在网页看板或微信里查看；会命令行更便于排障。

交付什么形式？

私有仓库只读 PAT + 部署教程 + 全部文档；数据首次运行时自己拉取。

不会部署怎么办？

可以按部署文档自己安装；也可选 200 元远程协助；暂时不部署可先申请看板试用。

后续策略更新怎么拿？

源码买断包含后续策略更新，作者打包到私有仓库，买家通过 git pull 同步。

源码能二次开发吗？

可以。交付完整源码、文档和 CLI，可在自己的项目里引用；禁止转售或再分发源码本身。

怎么试用？

88 元看板试用 5~7 个交易日，不含源码；试用期内购买源码可全额抵扣。

多久出结果？

竞价与选票在 09:26 前后；看天 09:27；盘中强多票每 30 分钟；复盘 16:19；明日观察按需生成。

策略会不会失效？

市场会变，不承诺永远有效；策略经过长期实盘验证与历史回测，仓库带有重标定与自评脚本。

2 核 2 GB 能跑吗？

支持。实测可稳定运行，常驻约 325 MB，最重作业峰值约 1.1 GB；也可装在自己电脑上。

和别家有什么区别？

全市场真实竞价、权威涨跌停口径、质量断言与可复权的本地数据湖，重点是可核对。

软件稳定吗？

原版与 PRO 版同一条路线已持续实盘运行超过一年，核心链路每日自动执行。

怎么咨询 / 试用？

购买源码付款备注微信；试用或看板需申请账号并由管理员审核，交流在看板内聊天。

原版怎么升级 PRO？

联系作者或在微信交流群里说一声，直接同步 PRO 版源码。
