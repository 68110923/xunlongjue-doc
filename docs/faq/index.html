购买与交付

交付什么形式？

永久看板：仅开通看板账号（永久权限）+ 拉微信群交流，不含源码、部署、CLI、PAT、数据快照；源码版：另发私有仓库只读 PAT + 数据快照密码 + 部署教程 + 全部文档，把部署页的两段话交给 AI 即可代你装好。

市场策略更新怎么拿？

永久看板的市场策略更新直接在看板内体现；源码版另通过私有仓库 git pull 同步，不另收费。

怎么试用？

88 元看板试用，有效期 7 个交易日，不含源码；付款后直接注册看板账号，不用留联系方式；试用期内购买永久看板或源码版可全额抵扣。

不会部署怎么办？

源码版可按部署文档自己安装，也可选协助部署 +200 元；只看板不部署，可先注册 88 元看板试用。

怎么咨询 / 试用？

购买 / 咨询：付款备注微信号，作者加你、拉群；永久看板由作者开通看板账号。看板试用：不用留联系方式，付款后直接注册，答疑在看板内。

已购买原版，怎么升级 PRO？

原版 xunlongjue 老用户升级政策不变，可直接同步 PRO 版源码；新购源码版按 2888 元。联系作者或在微信交流群里说一声即可。

源码能二次开发吗？

源码版交付完整源码、文档和 CLI，可在自己的项目里引用；禁止转售或再分发源码本身。对外提供基于本项目的 Web 产品时，须在产品页脚或关于页注明「本项目基于寻龙诀 PRO 二次开发」并链接官网。

部署与环境

部署需要什么环境？

Ubuntu 22.04+ 或自己的电脑，磁盘不少于 10 GB；系统时区必须是 Asia/Shanghai，否则定时任务会整体偏 8 小时且不报错。

2 核 2 GB 能跑吗？

支持。实测可稳定运行，常驻约 325 MB，最重作业峰值约 1.1 GB；也可以装在自己电脑上。

数据源 Key 谁付？

数据源免费，配置随交付提供；额外成本只有可选 AI 的 token 费用，约 0.2 元/天。

多久出结果？

竞价与选票在 09:26 前后；看天 09:27；盘中实时数据每分钟更新，预测与深度分析随时可用；复盘 16:19；明日观察按需生成。

使用与能力

这是什么？

部署在自己电脑或服务器上的 A 股量化研究工具：本地数据湖、一进二选票、个股预测、深度分析、仓位与复盘、网页看板与微信推送；核心层不依赖 AI。

完全不懂股票能用吗？

能看懂输出，但仍需自己判断。系统只给研究结论，不代下单、不承诺收益；建议先选 88 元看板试用。

会自动下单吗？

不会。不接券商、不代下单、不经手资金。

不接 AI 能用吗？

能。核心层零 LLM，数据、选票、复盘照常运行；AI 只负责推送话术和问答。

需要会编程吗？

不需要。装好后每天自动运行，结果在网页看板或微信里查看；会命令行更便于排障。

数据与稳定

数据保存在哪里？

源码版：全部保存在你自己的电脑或服务器；永久看板：数据在看板服务端，仅提供查看权限，不经过第三方。

和别家有什么区别？

永久看板 / 源码版买断后持续维护，市场策略长期更新：永久看板在看板内体现，源码版通过私有仓库 git pull 同步，不另收费；参数重标定、回测和自评脚本随版本更新。再加上全市场真实竞价、权威涨跌停口径、53 条质量断言与可复权的本地数据湖，重点是可核对、能长期用。

软件稳定吗？

原版与 PRO 版同一条路线已持续实盘运行超过一年，核心链路每日自动执行。

策略会不会失效？

市场会变，不承诺永远有效；策略经过长期实盘验证与历史回测，仓库带有重标定与自评脚本。
