功能说明

每天自动做什么、结果在哪里看、每个功能怎么用。

本页要点

  • 每天自动跑：竞价 → 选票 → 盘中扫描 → 复盘。
  • 六个功能：一进二、复盘、观察、预测、深度分析、两个出口。
  • 只做研究整理，不代下单、不承诺收益。

一天怎么跑

时间发生什么你会看到
09:25全市场真实竞价定盘竞价数据落库
09:26–09:27一进二候选≤3 只候选、买点类型、触发与放弃条件
盘中强多扫描按固定节奏更新的强多票
16:19每日复盘命中 / 遗漏 / 盲区 / 不该漏
盘后明日观察次日关注方向与条件

所有环节的产物都落到本地数据湖；网页看板和微信推送只读产物，互不依赖。

六个功能

一进二寻龙

做什么：全市场首板扫描，09:25 竞价定盘后给出候选（≤3 只）。

你会看到：候选、买点类型、触发条件、放弃条件、评分与硬闸结果。

依赖：真实竞价、涨停池、板块共振。

入口：网页看板 / 微信推送。

边界：只给研究结论，不代下单；不保证次日涨停。

每日自动复盘

做什么：收盘后汇总当日结果，区分命中、遗漏、盲区，并附「不该漏」清单。

你会看到：推送表现、命中/遗漏/盲区、漏在哪里、为什么漏。

依赖：当日推送、收盘行情、涨停与梯队数据。

入口：网页看板 / 微信推送。

边界：复盘是研究记录，不是收益承诺。

明日观察

做什么：盘后结合涨停梯队、板块合力、封板质量与竞价抢筹，梳理次日关注方向。

你会看到：少量核心标的、关注条件与放弃条件。

依赖：涨停梯队、板块强度、封板质量、竞价数据。

入口：网页看板 / 微信推送。

边界：观察是盘后研究，不预测次日一定上涨。

个股 / 大盘预测

做什么：发代码即回方向参考与关键指标；也能看当日涨跌家数、情绪档位与大盘系数。

你会看到：方向参考、关键指标、情绪与大盘环境。

依赖：长周期价量、指标与全市场统计。

入口：对话 / 看板。

边界：预测只作研究参考，不构成买卖建议。

深度分析

做什么：拉取长周期价量序列做结构化解析，辅助判断主力行为痕迹。

你会看到：形态、量能、指标分位与关键节点。

依赖：长周期日线、盘中快照与派生指标。

入口：对话 / 看板。

边界：分析结果不保证未来走势。

两个出口

做什么：同一份产物同时供给网页看板和微信推送；任选其一或都要。

你会看到：看板随时查看；微信推送可叠加 AI 分析。

依赖：display/*.json 产物；核心层零 LLM 也能运行。

入口：网页看板 / 微信推送。

边界：两个出口互不依赖，都只读产物。

功能、数据与策略的关系

功能主要输入输出去哪看
一进二真实竞价、首板、板块共振看板 / 微信推送
复盘当日推送、收盘行情看板 / 微信推送
明日观察涨停梯队、封板质量、竞价抢筹看板 / 微信推送
预测 / 深度分析长周期价量、指标对话 / 看板
两个出口display/*.json 产物看板 / 推送

功能负责「每天给你什么」，策略负责「为什么这样筛」，数据负责「结果能不能核对」。

每天看什么

  • 09:26：看候选和推送，先看触发条件与放弃条件。
  • 盘中：看强多票有没有新增，不反复刷新。
  • 16:19：看复盘，重点看「不该漏」。
  • 盘后：看明日观察，第二天竞价再验证。

边界

只做研究整理：不接券商、不代下单、不经手资金，也不承诺收益。所有候选都要自己判断。
