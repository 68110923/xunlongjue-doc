功能说明

本页要点

  • 每天自动跑：竞价 → 选票 → 盘中实时数据 → 复盘。
  • 六个功能：一进二、复盘、观察、预测、深度分析、两个出口。
  • 只做研究整理，不代下单、不承诺收益。

一天怎么跑

时间功能主要输入输出去哪看
09:25竞价定盘全市场真实竞价看板 / 微信
09:26–09:27一进二寻龙竞价、首板、板块共振看板 / 微信
盘中实时看板 / 预测 / 深度分析每分钟实时行情看板 / 对话
16:19每日复盘当日推送、收盘行情看板 / 微信
盘后明日观察涨停梯队、封板质量、竞价抢筹看板 / 微信

六个功能

01

一进二寻龙

09:25 竞价定盘后给出 ≤3 只候选，附买点、触发与放弃条件。

入口：看板 / 微信

02

每日自动复盘

收盘后汇总命中、遗漏、盲区，并附「不该漏」清单。

入口：看板 / 微信

03

明日观察

结合涨停梯队、板块合力、封板质量与竞价抢筹，梳理次日关注方向。

入口：看板 / 微信

04

个股 / 大盘预测

发代码即回方向参考；也能看涨跌家数、情绪档位与大盘系数。

入口：对话 / 看板

05

深度分析

长周期价量结构化解析，辅助判断主力行为痕迹。

入口：对话 / 看板

06

两个出口

看板与微信推送共用同一份产物；核心层零 LLM 也能跑。

入口：看板 / 微信

每天看什么

  • 09:26：看候选和推送，先看触发条件与放弃条件。
  • 盘中：看实时数据每分钟更新；需要时用预测、深度分析，或直接问 AI。
  • 16:19：看复盘，重点看「不该漏」。
  • 盘后：看明日观察，第二天竞价再验证。

边界

只做研究整理：不接券商、不代下单、不经手资金，也不承诺收益。所有候选都要自己判断。
