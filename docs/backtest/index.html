一进二策略怎么回测？

回测不是证明“策略能赚钱”，而是检查它在不同市场阶段是否稳定。

只看命中率很容易被误导：高命中率可能伴随大亏，低命中率也可能有正期望。一进二回测至少要看四个维度。

四个指标

  • 命中率：推送票次日涨停的比例。
  • 失败均亏：没涨停的票平均亏多少。
  • 7日最佳：买入后 7 个交易日内最高价相对买入价的涨幅。
  • 期望收益：胜率 × 均盈 + 败率 × 均亏。

容易忽略的偏差

样本太少、只挑上涨阶段、用收盘价而不是真实开盘价、忽略涨停买不进，都会让回测结果失真。回测要尽量使用当时可得的真实数据。

怎么用回测

回测还要看成本

一进二不是所有票都能按开盘价买到。一字板、秒板、竞价被抢，都会让真实成交价偏离回测。忽略可买性，回测会偏乐观。

样本怎么切

至少分上涨、震荡、下跌三种阶段看，不要只挑一段顺风期。样本太少的月份，不要把短期命中率当成策略结论。

常见问题

命中率高就代表策略好吗？ 不一定。还要看失败时亏多少、极端亏损、能否买到。

回测能预测未来吗？ 不能。它只能帮助排除明显不成立的想法。
