今天该进攻，还是先防守？

先定整体仓位，再谈个股；仓位区间是研究参考，不是满仓/清仓指令。

本页要点

  • 防守 0~2 成、均衡 3~5 成、进攻 6~8 成。
  • 看大盘趋势、涨跌家数、涨停/跌停、炸板率、中位数、最高连板。
  • 早盘给当天，复盘给次日；不构成投资建议。

三档仓位

  • 防守 0~2 成：大盘走弱、赚钱效应差、跌停多。
  • 均衡 3~5 成：方向不明、结构行情，试错为主。
  • 进攻 6~8 成：趋势向上、情绪回暖、涨停家数和连板高度都在改善。

为什么是这个仓位

先看上证趋势（多头/空头/震荡/反转），再看市场宽度：涨跌家数、涨停/跌停、炸板率、中位数、最高连板。趋势定大档，宽度做档内加减。

早上和收盘看的不一样

早盘用上一交易日数据，给当天仓位；收盘用当天数据，给次日仓位。两个时间点不要混着看。

常见误区

  • 把仓位建议当成个股买卖指令；它是整体仓位，不是每只票都买同样的比例。
  • 只看涨停家数，不看跌停、炸板和赚钱效应。
  • 空头趋势里重仓试错，或进攻趋势里一直空仓。

常见问题

仓位建议准吗？ 它是对市场状态的研究参考，不保证第二天涨跌；执行时还要结合自己的风险承受能力。

持仓票的仓位也看这个吗？ 整体仓位看这里；单票该拿还是该减看持仓与主力意图。
