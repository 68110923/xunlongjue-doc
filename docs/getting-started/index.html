安装与部署

把数据、策略和看板部署在自己的电脑或服务器上。

环境要求

  • Ubuntu 22.04+ 或自己的电脑，磁盘 ≥ 10 GB。
  • 系统时区必须是 Asia/Shanghai；时区不对会让定时任务整体偏移。
  • 2 核 2 GB 可跑日常流程；盘中扫描和全量回测建议错开。

首次启动

git clone <私有仓库>
cd xunlongjue-pro
uv sync
./.venv/bin/xlp doctor
./.venv/bin/xlp verify
./.venv/bin/xlp status

doctor 检查环境与数据源，verify 检查数据质量，status 查看湖内数据范围。

装定时任务

只选一个调度入口：systemd 或 crontab，不要同时装。

./.venv/bin/xlp cron install --system

装好后用 systemctl list-timers 'xlp-*' 检查全部作业。盘前与盘后是两条独立链，互不依赖。
