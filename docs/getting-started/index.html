安装与部署

付款后由作者主动联系，单独发送设备信息、私有仓库 PAT 和数据快照密码。公开页不保存任何密码或密钥。

安全提醒：服务器密码、PAT、API Key 和快照密码只通过私聊发送；不要贴到公开 issue、群聊或截图里。拿到后建议立即修改一次。

第一步：让 AI agent 装 DSH

把下面的任务和登录信息交给支持 shell 的 AI agent（豆包、Codex、DSH、Trae 等）。服务器信息付款后单独发送。

设备：服务器（推荐 Ubuntu 24.04）
IP / SSH 端口 / 用户 / 密码：付款后由作者单独发送

1) 安装或升级 Node.js，并设置 npm 镜像：
   npm config set registry https://registry.npmmirror.com

2) 安装并启动 DSH：
   npx @deepseek-ai/dsh web --no-open

3) 确认 DSH 宿主已配置开机自启。

4) 在 DSH 上安装插件：
   github:yjh051108/dsh-super-injector（第一个装）
   github:xmanrui/dsh-im
   github:68110923/dsh-mobile-ux

5) 服务器上通过 SSH 隧道访问 DSH：
   ssh -L 3081:127.0.0.1:3080 -p <SSH端口> <用户>@<服务器IP>

本地电脑直接打开 DSH 给出的地址；服务器则打开本地 http://127.0.0.1:3081。

第二步：配置 DeepSeek 与 IM 机器人

  1. 给 DeepSeek 充值少量 token 费用：platform.deepseek.com。可以创建 API Key 填到 DSH 的「设置 → 模型」，也可以直接登录账号。
  2. 打开 DSH，找到「IM 机器人」，绑定微信、钉钉或其他使用方式。
  3. DSH-IM：设置 → 更多设置 → 投递设置 → 新建投递目标，勾选「会话双向同步」，点测试确认能收到消息。
  4. DSH-IM 右上角：设置 → 投递，勾选「投递模型回答」并保存。

第三步：部署寻龙诀 PRO

  1. API Key：前往 fuyao.aicubes.cn 注册并获取，填入项目配置。
  2. 付款后作者会单独发送私有仓库只读 PAT；用它克隆源码：
git clone https://github.com/68110923/xunlongjue-pro.git
cd xunlongjue-pro
uv sync
./.venv/bin/xlp doctor
./.venv/bin/xlp verify
  1. 按仓库内 docs/DEPLOY.md 完成数据、定时任务和看板部署。
  2. 首次拉取数据快照时，使用作者单独发送的快照密码；不要把密码写进仓库或公开文档。

部署完成后

先跑 xlp doctor、xlp verify、xlp status，确认环境、数据和质量检查都正常，再开启定时任务。
