安装与部署

本页要点

  • 设备自己准备：本地电脑或云服务器；示例里的 IP、端口、密码只是占位。
  • 你只需要把两段话发给 AI，装 DSH、部署、拉数据都由它完成。
  • PAT 和快照密码付款后私聊发送；作者不会索要你的服务器密码。

第一步：准备设备

本地电脑

Windows / macOS 都行。数据留在自己电脑上，不用买服务器。

  • 磁盘 ≥ 10 GB
  • 系统时区 Asia/Shanghai
  • 电脑关机时不会自动跑

云服务器

推荐 Ubuntu 24.04，2 核 2 GB 即可。适合 24 小时自动采集与推送。

  • 磁盘 ≥ 10 GB
  • 系统时区 Asia/Shanghai
  • 常驻约 325 MB

不想买服务器？本地电脑也能装。云服务器只是让定时任务 24 小时在线。

第二步：让 AI 装 DSH

豆包、WorkBuddy、Codex、DSH、Trae 等皆可，AI 装好 DSH 之后会告诉你访问链接。

第一段话 · 复制发给 AI

设备：<本地电脑 / 云服务器 Ubuntu 24.04>
（服务器填写）IP：<你的服务器 IP>，SSH 端口：<你的端口>，用户：<root>，密码：<你的密码>
（本地电脑填写）操作系统：<Windows / macOS>

请帮我完成：
1) 安装或升级 Node.js；npm 镜像设为 https://registry.npmmirror.com/
2) 安装并启动 DSH：npx @deepseek-ai/dsh web --no-open
3) 确认 DSH 宿主已配置开机自启
4) 在 DSH 上按顺序安装插件：
   github:yjh051108/dsh-super-injector（必须第一个）
   github:xmanrui/dsh-im
   github:68110923/dsh-mobile-ux
5) 如果是服务器：在我本地建立 SSH 隧道，告诉我本地访问地址
   ssh -L 3081:127.0.0.1:3080 -f -N -p <SSH端口> <用户>@<服务器IP>
   如果是本地电脑：直接给我 DSH 的完整访问链接

不知道服务器信息在哪？服务器商控制台里有 IP、SSH 端口和 root 密码；本地电脑只需要告诉 AI 是 Windows 还是 macOS。

第三步：在 DSH 里绑定微信 / 钉钉

  1. 给 DeepSeek 充 10 元（token 费用）：platform.deepseek.com/usage。二选一：创建 API Key 填到「设置 → 模型」，或直接登录账号。
  2. 打开 DSH 链接，找到「IM 机器人」，绑定微信、钉钉或其他使用方式。
  3. 配置投递：DSH-IM → 设置 → 更多设置 → 投递设置 → 新建投递目标 → 勾选「会话双向同步」→ 点测试，确认能收到消息。
  4. 打开模型回答投递：DSH-IM 右上角 → 设置 → 投递 → 勾选「投递模型回答」→ 保存。

验收标准：测试消息能在微信 / 钉钉里收到，再进入下一步。

第四步：让同一个 AI 部署寻龙诀

  1. 注册 fuyao 获取 API Key：前往 fuyao.aicubes.cn 注册并获取。
  2. 付款后作者私聊发你两样东西：私有仓库只读 PAT、数据快照密码。不要贴到公开群、issue 或截图里。
  3. 把下面整段发给刚刚绑定好的机器人，让它自己 clone、装依赖、拉快照、配置定时任务：

第二段话 · 复制发给机器人

API Key：<你的 fuyao API Key>
PAT：<付款后作者私聊发送>
数据快照密码：<付款后作者私聊发送>

请按 https://github.com/68110923/xunlongjue-pro 的 docs/DEPLOY.md 部署寻龙诀 PRO：
1) 用 PAT 克隆私有仓库
2) 按 DEPLOY.md 安装依赖、配置数据与定时任务
3) 用快照密码拉取数据快照
4) 部署完成后运行 xlp doctor、xlp verify、xlp status，把结果发给我

只私聊：PAT、快照密码、API Key 不要发到公开群、issue 或截图里。作者不会索要你的服务器密码。

部署完成验收

AI 会跑下面三条命令；三条都正常，再开启定时任务。

./.venv/bin/xlp doctor
./.venv/bin/xlp verify
./.venv/bin/xlp status

看到环境、数据和质量检查都通过 → 可以申请看板账号（购买与试用流程见 定价页）。

需要协助？

不想自己折腾，可以选择 200 元远程协助；付款后作者会联系你，约 2 小时完成。设备仍然由你准备。
