策略总览

一进二不是单一指标，而是一条“先排除、再排序、最后交给竞价”的流程。

本页要点

  • 首板池先做硬条件过滤，再做评分和板块共振。
  • 09:25 竞价定盘后，用真实竞价做最后确认。
  • 筛选只能提高研究效率，不能保证结果。

三段结构

  • 首板池：先确定当天有哪些首板，排除明显不合适的票。
  • 评分与共振：把位置、量价、板块和风险放进同一套比较。
  • 竞价确认：09:25 后再用真实竞价决定能不能参与。

阅读顺序

A 股一进二是什么：首板到二板的基本逻辑。

竞价打板怎么看：09:25 竞价数据怎么用。

龙虎榜怎么看：机构和游资数据怎么读。

边界

任何筛选都只能提高研究效率，不能保证结果。策略、数据和回测方法要一起看，不要用一个指标代替判断。
