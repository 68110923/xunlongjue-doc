A股一进二是什么？

一进二不是“看到首板就买”，而是从首板里筛出次日更可能继续走强的候选。

“一进二”指首板之后，次日能否继续涨停、走出二板。首板只说明当天有资金把它推到涨停；第二天能不能接住，取决于竞价、位置、量价、板块和情绪。

首板只是起点

首板数量每天可能几十只，真正能进入研究范围的是少数。寻龙诀 PRO 会把首板池先做硬条件过滤，再做评分和板块共振，最后按区间排序。

核心判断维度

  • 竞价：高开多少、竞价量够不够、有没有被抢筹。
  • 位置：是否处于低位、是否已经连续上涨、是否离均线过远。
  • 量价：封板时间、换手、成交额、炸板情况。
  • 板块：同板块涨停家数、连板高度、是否形成共振。
  • 风险：高开低走、单边下跌后急反弹、涨停密集等。

常见误区

为什么首板多、二板少

首板只需要当天资金推动，二板还要经过隔夜情绪、竞价承接和盘中分歧。大部分首板会在次日被淘汰，所以筛选的目标不是“找最强”，而是先把明显不合适的票排除掉。

筛选不是预测

任何筛选都只能提高研究效率，不能保证结果。位置、竞价、量价和板块要一起看，单独一个条件很容易得出相反结论。

常见问题

首板数量越多越好吗？ 不一定。首板过多可能意味着情绪扩散，也可能意味着次日分歧更大。

竞价高开就一定能买吗？ 不一定。高开还要看量能、位置和板块，过高也可能变成兑现。
