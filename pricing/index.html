怎么试用？

88 元看板试用 5~7 个交易日，不含源码，结果在看板内查看；试用期内购买源码可全额抵扣。

交付什么形式？

私有仓库只读 PAT + 数据快照密码 + 部署教程 + 全部文档；把部署页的两段话交给 AI 即可代你装好。

不会部署怎么办？

可以按部署文档自己安装；也可选 200 元远程协助（约 2 小时）；暂时不部署可先申请看板试用。

后续策略更新怎么拿？

源码买断包含后续策略更新，作者打包到私有仓库，买家通过 git pull 同步，不另收费。

怎么咨询 / 试用？

购买源码：付款备注微信，加微信后拉进微信交流群；试用 / 看板：付款后申请看板账号（需审核），交流在看板内的聊天。
